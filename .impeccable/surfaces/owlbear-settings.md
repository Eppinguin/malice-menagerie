# Owlbear extension settings

Visitor mode: Operate. Directors configure the companion in Owlbear's 360px popover.

## Direction contract

THESIS: A compact Owlbear-native settings list, ordered by everyday usefulness. Token appearance is the main preference; custom hosting is an advanced exception.
OWN-WORLD: Owlbear's live theme palette, Roboto/system sans, Material-style switches, outlined fields and restrained dividers. This embedded surface intentionally uses the host grammar rather than the app's printed-book identity.
STORY: Open/connect to the official Malice app, choose initials or opt into TooManyTokens, configure Sync (Rings Initiative and Condition labels), and optionally connect dice. Settings persist in this browser; existing artwork stays intact.
FIRST VIEWPORT: Small product header and compact connection actions, token appearance switch with initials preview, Sync controls, and dice connection/theme. Advanced server settings and concise usage help follow below.
FORM: User-pinned Owlbear-native settings panel, directly shaped for the specified narrow surface; no concept roll.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
